# خارطة طريق غرفة أخبار النقطة

آخر تحديث: 2026-09-29

## المنجز حالياً

- Supabase هو المصدر الوحيد للمواد العامة وحسابات الفريق والصلاحيات.
- الصفحة الرئيسية وغرفة الأخبار تعرضان المواد المنشورة مباشرة من `articles`.
- الأدوار التحريرية مفعّلة: Owner وEditor وWriter وأدوار الإنتاج البصري.
- النشر محصور بالـOwner، مع تحقق من جاهزية المادة وفرض AAL2 عند النشر.
- المصادقة الثنائية TOTP متاحة من واجهة غرفة الأخبار.
- سجل التدقيق التحريري وصندوق المعلومات وإدارة النشرة متاحة للـOwner.
- ClickUp يرسل المواد إلى المراجعة، ولا ينشرها تلقائياً.
- صفحات السياسات والخصوصية والتصحيحات والتواصل منشورة.
- GitHub Actions يبني CSS ويفحص الموقع قبل نشره على GitHub Pages.

## الأعمال التالية ذات الأولوية

1. إعداد SMTP خارجي موثوق للدعوات واستعادة الحساب وتأكيد النشرة.
2. إضافة تنبيه بريدي عند وصول مادة جديدة إلى صندوق المعلومات.
3. إضافة فحص برمجيات خبيثة للمرفقات قبل إتاحتها للمحررين.
4. تفعيل Turnstile تدريجياً بعد اختباره على شاشة الدخول والاسترداد.
5. تحسين معاينة روابط المقالات على شبكات التواصل عبر صفحات ثابتة أو خدمة prerender.
6. ربط صفحات التحقيقات والوثائق بمزيد من الحقول التحريرية عند توفر مواد فعلية.
7. إضافة نطاق رسمي للموقع ثم تحديث canonical وOpen Graph وSMTP عليه.

## قرارات ثابتة

- ClickUp أداة إعداد وإرسال للمراجعة، وليس سلطة نشر.
- GitHub لا يُعد مصدر المقالات المنشورة؛ ملفات `content/posts` أرشيف مسودات فقط.
- لا تُعرض المسودات أو المواد قيد المراجعة للعامة.
- لا توجد قناة تدّعي حماية المصادر الحساسة أو إخفاء الهوية؛ نموذج الإرسال الحالي
  مخصص للمعلومات العامة وفق سياسة الاحتفاظ المنشورة.
- أي ميزة أمنية أو تحريرية لا تُعد مكتملة قبل نجاح الاختبار ومسار النشر.
