# نموذج التهديد — إرسال معلومة أو وثيقة

هذه الميزة صندوق استقبال صحفي خاص، لكنها **ليست SecureDrop** ولا تضمن إخفاء هوية المصدر.

## ما نحميه

- نص المعلومة والوثيقة المرفقة.
- منع القراءة العامة أو الوصول المباشر للملفات.
- تقليل الرسائل الآلية والإغراق.
- حصر المعالجة داخل حسابات `owner` و`editor`.

## الضوابط المطبقة

- الإدخال العام يمر عبر Edge Function ولا يملك صلاحية كتابة مباشرة إلى الجدول أو التخزين.
- Bucket خاص منفصل عن `newsroom-media` العام.
- RLS للقراءة والتحديث، وروابط تنزيل موقعة قصيرة العمر.
- ملف واحد اختياري بحد 10 MB، ومسموح فقط PDF وJPEG وPNG وWebP.
- حدود لطول العنوان والتفاصيل، حقل honeypot، وخمس محاولات لكل بصمة شبكة خلال ساعة.
- لا يُخزن عنوان IP الخام؛ تُخزن بصمة أحادية الاتجاه وتُحذف قيودها القديمة تلقائياً.
- لا تُرسل الوثيقة كمرفق بريد إلكتروني.

## مخاطر باقية

- الملفات لا تمر حالياً عبر فحص malware؛ يجب فتحها بحذر وفي بيئة معزولة.
- مزود الاستضافة وSupabase قد يحتفظان بسجلات تشغيل واتصال وفق سياساتهما.
- PDF أو الصور قد تحتوي Metadata تكشف المصدر.
- الحد من الإساءة ليس بديلاً عن CAPTCHA/WAF عند ارتفاع الهجمات.
- لا يوجد حتى الآن تنبيه بريدي؛ الصندوق الداخلي هو قناة المراجعة الحالية.

## تشغيل ومراجعة

- لا توسّع صلاحيات bucket إلى public.
- راجع سجلات Edge Function بدون طباعة النص أو أسماء الملفات.
- ضع سياسة احتفاظ وحذف قبل استقبال مواد حساسة فعلياً.
- أضف فحص malware وخدمة تنبيه خلفية قبل وصف النظام كقناة مصادر حساسة.
