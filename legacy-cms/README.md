# Legacy CMS archive

أزيلت إعدادات TinaCMS وDecap والمادة التجريبية من مسارات التشغيل، وهي متاحة في
تاريخ Git عند الحاجة للمراجعة. هذه الملاحظة فقط لتوثيق قرار العزل.

Supabase هو مصدر مواد غرفة الأخبار الوحيد. لا تعِد ملفات CMS القديمة إلى
`admin/` أو `public/admin/` أو `content/posts/` من دون قرار صريح بإعادة تفعيل
CMS ثانٍ ومراجعة تعارضه مع Supabase.
